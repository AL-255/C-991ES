# Ordinary input/evaluation controller

`fx_input_controller` expresses the ordinary COMP/CMPLX F12A transaction in readable C. Its context, temporary expression, variable bank, saved result and wait state belong to the host. Production code neither executes firmware nor writes a synthetic CPU call frame into calculator RAM.

`fx_input_controller_begin` applies the native initial history/result gates, stores the input address at812C, calls direct or natural input preparation, selects a pending colon source when required, and preserves the old twenty-byte result. `FX_INPUT_PREPARED` is the native F2AC checkpoint immediately before evaluation. Empty input and the implemented replay/reset gates complete synchronously.

A prepared `tick` sleeps the display port and calls the shared controlled evaluator once. The evaluator receives the current variable bank, angle unit and resolved exact-output permission. Colon ends the host expression while its original byte remains on the bus. The result status controls the transaction: ordinary success commits variable changes, resets display flags/initial format, preserves prior COMP Ans at828A, stores Ans, records colon continuation and appends replay. EA0C classification uses the original814A source and companion zero, the remaining-copy count proven by the native Ans-store flow.

Evaluator errors preserve the original imaginary record until the native clear/recovery stage, map the consumed source cursor back to the natural editor when needed, and start the existing nonblocking error controller. A wait tick may return `WAIT`, `EXPORT` or a host `RESET` request. Accepted key tokens write80F5 and80F7 before5176 clears the result. The saved result is restored when the context requires it, then EC72 cursor recovery and E67C context recovery determine action0 or1. Raw8E01/8E02 key bytes remain intact for the host to clear after consumption.

Continuous evaluation uses the existing5550/5564 host handshake. Each callback installs the sampled X record, requests host service, and records cancellation through the original persistent flags. A successful callback clears8E00; a cancellation follows the native error path. The canonical suite compares every callback count and sampled X record for finite series, integral and derivative transactions.

`finish` consumes completion while retaining the named context in the state. Native F12A actions are0 for reset/no-op,1 for editable recovery and2 for result redraw. `present` performs ordinary EE7C natural or linear expression refresh, calls B070 when the current state displays a result, and applies the outer DC64 replay-navigation flag. It does not consume completion, so a caller can inspect or present the state before finishing.

The linear helper implements8282 with host character buffers. ROM pointers and descriptors expand each token, including implicit opening parentheses and the COMP C8..CA alternate labels.81B0 selects the first visible token using the original byte-valued cursor/budget arithmetic. The helper captures cursor geometry, pads the row and draws left/right markers through the shared glyph engine. TABLE range labels/prefixes are outside this ordinary entry. C674 tests TABLE mode88/screen1;4F26 evaluates its start/end/step fields at829E/82A8/82B2. These entries are not the numerical SOLVE routine.
